# Roadmap

## Phase 1

- 本地 TXT 导入
- 自动解析章节目录
- 双页阅读与基础翻页
- 设置持久化
- 本地书签和进度

## Phase 2

- 大文件虚拟分页
- JSON 备份恢复
- storage.sync 同步轻量配置

## Phase 3

- Google Drive 备份
- OneDrive 备份
- 发布优化与商店材料

## Phase 4（v0.6 稳定性 + 数据闭环）

- 编码自动识别与防乱码（UTF-8 / UTF-16 / GB18030 / Big5）
- 无目录书段落平铺兜底
- 加载中 / 空 / 错误 / 阅读中四态界面
- 大章节增量分页、章节分页缓存、空闲预热
- 可选匿名错误上报（默认关闭）

## Phase 5（v0.7 可用性增强）

- 首次引导与设备自适应默认值
- 阅读统计细化（速度、预计剩余、连续天数）
- 多设备同步冲突裁决（保留本地 / 保留云端 / 逐字段合并）
- 无障碍：焦点陷阱、跳转正文、页码播报、WCAG AA 对比度
- 批量导入与拖拽投放、最近文件
- 三档场景模式（日间 / 夜间 / 护眼）

## 待定

- 书源 / 在线书库（需先确认版权与合规边界）
- TTS 朗读
- 多语言界面扩充（当前 zh_CN + en）
- 桌面端独立阅读器（视需求评估）

# Xyfy.TxtReader v0.7 可用性增强 PRD

> 版本：v0.7.0 ｜ 主题：**可用性增强**（新手上手 + 日常顺手）
> 对应 Epic：[#29](https://github.com/xyfy/Xyfy.TxtReader/issues/29)

## 1. 背景

v0.6 把「能不能读」的问题收敛完了：大文件不卡、编码不乱、章节识别准、异常有出口、错误可观测。
但从真实使用路径看，剩下一层摩擦全在**入门与顺手**上：

| 现象 | 根因 |
|------|------|
| 新用户打开是一张空白双页，不知道能拖拽、不知道有快捷键 | 没有引导，能力全靠自己发现 |
| 统计面板只显示「现在在哪」，看不出读了多少 | 只有位置快照，没有行为统计 |
| 多设备同时改设置，后同步的一方被静默覆盖 | `chooseNewerRecord` 只比时间戳，不提示冲突 |
| 键盘用户 Tab 会跑到浮层背后的侧栏；预设主题对比度从未校验 | 无障碍是事后补的，不是约束 |
| 换书要点「选择文件」，一次只能导一本 | 导入路径单一 |
| 切夜间要开设置动下拉 | 高频操作路径太长 |

v0.7 的目标是：**让新用户 30 秒内读起来，让老用户少点两次鼠标。**

## 3. 功能详述

### FR-S1 首次引导与默认值

**目标**：把「能拖拽 / 有快捷键 / 进度自动存」这三件最有价值的事，在用户第一次打开时讲清楚；同时给出与设备匹配的初值。

**规则**

1. 引导为 3 步模态卡片（导入 / 阅读 / 备份），最后一步按钮文案变为「开始阅读」。
2. 展示条件（三条同时满足）：`onboardingDone !== true`、书架为空、`onboardingVersion < ONBOARDING_VERSION`。
3. 跳过与完成同等落盘（`onboardingSkipped` 区分，便于日后评估引导有效性），刷新不再出现。
4. 默认值推荐按视口宽度分三档，触摸设备行高 +0.1，矮视口（<480px）字号回退一档。
5. **只在 `settingsTuned === false` 时应用推荐值**，用户手动调过版式后一律不覆盖。

**不做的事**：不持久化「单页/双页」。它由 `detectPagesPerView` 按实时视口决定，写进设置会让窗口拉窄后卡在双页挤压状态。

### FR-S2 阅读统计细化

**目标**：回答用户三个问题——今天读了多久、读得多快、这本还剩多久。

**规则**

1. 时长按本地日期分桶；单次会话封顶 4 小时，低于 5 秒的碎片不计。
2. 空闲判定：连续 120 秒无翻页/滚动视为暂停，不计时；页面不可见时不计时。
3. 速度为「字/分钟」，样本不足返回 `null`（UI 显示「—」），并夹紧在 50~3000 之间。
4. 剩余时长 = 剩余字数 ÷ 速度；已读完显示「已读完」，速度未知显示「—」。
5. 连续天数从最近阅读日往回数，今天还没读不清零。
6. 明细保留 30 天（`pruneHistory`），汇总累计值不裁剪。

**数据边界**：全部落本地存储，不参与 `storage.sync`，不上报。

### FR-S3 同步冲突体验

**目标**：把「静默丢配置」变成「明确告知 + 可裁决」。

**规则**

1. 冲突判定：两侧内容不同 **且** 更新时间差 ≤ 5 分钟（`CONFLICT_WINDOW_MS`）。差得远视为多设备接力，仍按新的胜出，不打扰。
2. 参与比对 11 个偏好字段；`onboarding*`、`scene` 等非偏好状态不参与，避免假冲突。
3. 三种裁决：保留本机 / 保留云端 / 两者合并。
4. 「两者合并」以较新一方为底，把「对方改过、我这侧仍是默认值」的字段捡回来；`themeColors`、`keybindings` 按 key 互补。
5. 裁决后 `settingsUpdatedAt` 严格大于两侧，防止下次读取回滚。
6. 启动时**先取快照判冲突，再走会写回的 `getReaderSettings`**，否则冲突一侧当场被覆盖。

### FR-S4 无障碍

**目标**：键盘、读屏、弱视力用户都能完整使用。

**规则**

1. 三个浮层（设置 / 快捷键 / 引导）启用焦点陷阱：Tab 在容器内循环，关闭后焦点归还触发元素。
2. HTML 语义补齐：`role="dialog"` + `aria-modal` + `aria-labelledby`；页码 `aria-live="polite"`；首元素为「跳到正文」。
3. 预设主题必须通过 WCAG AA 审计：正文对比度 ≥ 4.5:1，强调色（UI 组件）≥ 3:1。
4. 设置面板新增「无障碍」分区，实时显示当前配色的最低对比度与不达标项。
5. `modules/a11y.js` 的调色板常量必须与 `reader.css` 实际值一致，由测试断言防止漂移。

### FR-C1 导入体验增强

**规则**

1. 拖拽：拖入阅读区即导入，落区有实心虚线提示；离开时正确收起（用 enter/leave 计数，避免子元素抖动）。
2. 筛选：只收 `.txt` 或 `text/plain`；空文件、>20 MB、同批次重复一律拒绝并说明原因。
3. 批量：一次可选多个文件，串行导入；单个失败不中断，结束后打开最后一个成功项。
4. 最近文件：容量 8，按「名称 + 大小」去重，重复导入移到最前；书已删除时点击给出提示而非死链。

### FR-C2 场景模式

**规则**

1. 三套预设：日间（paper / 18px / 1.8）、夜间（night / 18px / 1.9）、护眼（sepia / 19px / 2.0）。
2. 严格反查：主题、字号、行高三项全等才高亮，手调过字号则全部熄灭。
3. **不动 `themeColors`**：从自定义配色切场景再切回，用户调好的颜色必须还在。
4. 切换时若存在有效自定义配色，提示「自定义配色已保留」，避免用户以为被清空。

## 4. 非功能要求

- 六个功能的纯逻辑必须能脱离 DOM 在 Node 下测试，`reader.js` 只做接线。
- 新增设置项一律有默认值，旧设置经 `normalizeStoredSettings` 自动补全。
- 双端（扩展 / 站点）HTML id 完全一致，文案中英双语齐全。
- 新增数据（阅读统计、最近文件）仅本地存储，隐私政策同步说明。

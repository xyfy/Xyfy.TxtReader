# v0.6 测试样本集

对应《v0.6 测试用例与测试计划》第二节「测试样本集（需准备）」，共 9 类 11 个文件。

## 生成

样本由脚本确定性生成，不入库（已加 `.gitignore`），任何机器跑出来的字节完全一致：

```bash
npm run gen:samples                # 大文件样本 100 万字（约 2.9 MB）
node scripts/gen-test-samples.mjs --scale 3.5   # 放大到约 10 MB，用于 TC-M1-01 的 10MB 档
```

输出到本目录。GBK 编码表由 Node 内置的 `gb18030` 解码器反查得到，不引入额外依赖。

## 自动化覆盖

`npm run test:samples` 会把上面每个样本真实跑一遍
**解码（FR-M2）→ 分章（FR-M3）→ 分页（FR-M1）→ 边界判定（FR-M4）** 全链路，
断言编码识别结果、乱码字符、章节数、段落是否被切断、分页是否溢出/空白，以及样本集可复现性。

以下部分仍需手工验证（机器无法判定「界面上看到什么」）：

- 导入大文件时是否真的看到加载态（TC-M4-01）
- 空态是否带导入入口（TC-M4-02）
- 错误态是否显示原因文案与「重试」按钮、编码不可识别时是否出现编码下拉（TC-M4-03）
- 连续翻页 50 页是否流畅无脚本错误（TC-M1-01）

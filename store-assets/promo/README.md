# 宣传图（promo）—— 可选

本目录用于存放 Chrome / Edge 商店的「宣传图」（promotional images）。

⚠️ **仓库不预置任何图片**：宣传图属于营销素材，需要你按下方规格用设计工具自制。

| 规格 | 用途 | 优先级 |
|------|------|--------|
| 440×280 | 搜索结果卡片小图 | 低 |
| 920×680 | 详情页顶部大图 | 中 |
| 1400×560 | Featured 推广横幅（需向 Google 申请） | 低 |

## 建议

第一版**先不传宣传图**，直接提审，过审后再补。少一个变量，少一次被打回。
详见 `docs/release-manual.md` 第 2.3 节。

## 用法

1. 用设计工具按上表尺寸出图（PNG，清晰、不含侵权内容）。
2. 放进本目录，例如：`440x280.png`、`920x680.png`、`1400x560.png`。
3. 在商店后台对应位置分别上传。

## 与截图的区别

- **截图（screenshots/）**：由 `npm run shots` 自动生成，是商店必填项，照着跑脚本即可。
- **宣传图（promo/）**：可选，需自制，本目录只是给你一个放图的位置。
